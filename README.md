# Python Darts Master

ダーツゲームのシミュレーション及びアニメーション生成プロジェクト

## 概要

このプロジェクトは、Pythonで実装されたダーツゲームアプリケーションです。tkinterを使用したGUIと、Manimライブラリを使用したアニメーション生成機能を備えています。

## 機能

- **ダーツゲームシミュレータ**：TkinterベースのダーツボードUI
- **複数のゲームモード**：COUNTUP、ダブルアウトなど複数のモードに対応
- **クリケットゲーム対応**：クリケットゲームのターゲット設定
- **HIDDEN CRICKET**：7つのターゲットをランダム抽選し、当たるまで非公開にするモード
- **見やすいスコア表示**：選択中のモード・投球中のプレイヤーを強調し、スコアとマークを差分更新
- **可変レイアウト**：画面サイズに合わせてボードを調整。ALL CRICKETの全21ターゲットは表示領域の高さに合わせて行・文字を拡大し、全画面でも表全体を一覧表示
- **ダーツ盤の色分け**：元の配色に50%の色を重ね、相手に加点できる的は赤、まだ埋める的は黄色に色付け。全員クローズ済み・対象外の的には色を重ねず元の配色を表示。HIDDEN CRICKETでは未発見の的は一律に黄色、当てて対象外と分かった的は元の配色に戻す（UNDO対応）
- **ゲーム操作**：NEW GAMEで再開、UNDOで投球・スキップを取り消し。終了時は画面内に勝者を表示
- **ダブルアウト表**：高スコア達成時の推奨ダーツ配置を提示
- **アワード動画**：5〜9 COUNT、WHITE HORSE、THREE IN THE BLACKなど全15種類の動画をアプリ内で自動再生（無音・スキップ可能）
- **メンバー管理**：名前・写真を登録し、ドラッグで順番を変更。選択した最大4人のメンバーで対戦
- **成績保存**：完了した試合の勝敗、モード別成績、BULL・アワード回数を保存。試合終了のUNDOにも対応
- **アニメーション生成**：Manimの従来素材に加え、同梱動画をPillowとPyAVで再生成可能

## 必要要件

- Python 3.8以上
- tkinter（Pythonに付属）
- Pillow、av（写真表示・アワード動画再生。`requirements.txt`で導入）
- manim（従来の`animation.py`を使う場合のみ）
- tkmacosx（Mac環境でのUI改善用、オプション）

## インストール

```bash
# 仮想環境の作成
python -m venv .venv

# 仮想環境の有効化
source .venv/bin/activate  # Mac/Linux
# または
.venv\Scripts\activate  # Windows

# 依存パッケージのインストール
pip install -r requirements.txt
pip install tkmacosx  # macOSで色付きボタンを使う場合（任意）
pip install manim     # 従来のManim素材を生成する場合（任意）
```

## 使用方法

### ダーツゲームアプリの起動

```bash
python main.py
```

Tkinterベースのダーツボード表示ウィンドウが起動します。

### メンバーと成績

1. **MEMBERS**でメンバー管理を開き、名前と任意の写真を設定して**保存**します。
2. 各メンバーを選んで**参加**にチェックします（最大4人）。一覧の行をドラッグすると、一覧と投球順を並べ替えられます。
3. **この順でゲーム開始**で現在のモードの新しい試合を開始します。進行中の試合は最初からになります。
4. 試合終了時に、登録メンバーの成績を自動保存します。**MEMBERS**で名前を選ぶと成績・最近の試合を確認できます。

ゲストは登録なしでもプレイできます。**ゲストで開始**で切り替え、**NAMES**でゲスト名を変更できます。登録メンバーの名前は**MEMBERS**から編集します。参加人数を増やすと追加枠はゲストになります。

成績は完了した試合のみが対象です。平均投点は投球の素点（BUST時の命中点も含む）を投数で割った値です。クリケットのMPRは有効な的に当てたマーク数÷投数×3で、発見ボーナスは含みません。COUNTUPのベストは最高点、01とクリケットは最小の終了時スコアです。

データはプロジェクト内の`data/members.sqlite3`と`data/photos/`に保存します。写真は管理用コピーを作るため、元の写真を移動しても表示できます。別PCへ移す場合は`data/`フォルダ全体をコピーしてください。保存先は環境変数`DARTS_DATA_DIR`で変更できます。

### アワード動画

アワード達成時は、達成したプレイヤー名と専用の約3.6秒の動画を表示します。**Esc / Space / SKIP**で閉じられます。再生中は次の投球を受け付けません。ヘッダーの**アワード動画**チェックで再生を無効にできます（アワードの成績は記録されます）。動画を読み込めない場合はタイトル表示に切り替わります。

[DARTSLIVEの公開条件](https://dlapp.zendesk.com/hc/ja/articles/360055745754-AWARD%E3%81%AE%E5%87%BA%E7%8F%BE%E6%9D%A1%E4%BB%B6)を参考に、次のアワードを用意しています。動画は種類ごとに構図と動きが異なるオリジナル演出です。

| アワード | このアプリでの条件・演出 |
| --- | --- |
| ONE BULL | 1ラウンドにBULLが1本。緑のスキャングリッドと「NICE ONE!」 |
| LOW TON / HIGH TON | COUNTUP・01の1ラウンドで100〜150点 / 151〜180点。青い立方体 / 黄金のタワー |
| HAT TRICK | BULLに3本。赤いターゲットと衝撃波 |
| THREE IN A BED | 同じ数字・同じDOUBLEまたはTRIPLEに3本。紫の3レーンが合流（クリケットは有効な的のみ） |
| TON 80 | COUNTUP・01でT20に3本。オレンジの巨大180 |
| THREE IN THE BLACK | D-BULLに3本。白黒の奥行きトンネル |
| WHITE HORSE | クリケットで異なる3つの有効な的にTRIPLE。疾走する馬のシルエット |
| HIGH OUT | 01でラウンド開始時の残り100点以上からフィニッシュ。ピンクの加速する光線 |
| 5 / 6 / 7 / 8 / 9 COUNT | クリケットで1ラウンドの有効マーク数が5〜9。マーク数ごとに色が変わる巨大数字とゲージ |
| WINNER | 試合終了時の勝者。金色の王冠 |

クリケットのCOUNTはラウンド終了・SKIP・フィニッシュ時に確定します。投球時点で全員が閉じた的や対象外の的は0マーク、HIDDENの発見ボーナスは含めません。ALL / INVERSE / HIDDENでも、そのゲームの有効な的で判定します。BULLはS-BULL=1、D-BULL=2マークです。

複数条件を満たした場合は、特別なアワードをメイン動画にし、同時達成したCOUNTなどを上部に併記します。成績にはすべてを記録します。たとえばWHITE HORSEは9 COUNT、THREE IN THE BLACKはHAT TRICKにも加算されます。UNDO時は関連するカウントも戻ります。

同梱の動画は`media/awards/`にあります。再生成する場合：

```bash
python tools/render_awards.py
```

### 検証

```bash
python -m unittest discover -s tests -v
python tests/gui_smoke.py  # デスクトップ画面が必要。一時フォルダのデータで検証
```

### アニメーション生成

```bash
manim -pl animation.py HatTrickAward
```

「Hat Trick Award」アニメーションが生成されます。

## ゲーム設定

`config.py`で以下の設定をカスタマイズ可能：

- **SEGMENTS**：ダーツボードのセグメント配置（時計回り）
- **CRICKET_TARGETS**：クリケットゲームのターゲット
- **CRICKET_TARGET_POOL**：HIDDEN CRICKETで使う候補数字
- **HIDDEN_CRICKET_TARGET_COUNT**：HIDDEN CRICKETで使う数字の数
- **DOUBLE_OUT_TABLE**：ダブルアウト表の推奨配置

HIDDEN CRICKETでは、ゲーム開始時に1〜20とBULLの候補から7つを抽選します。最初にその数字を当てたプレイヤーには、事前に選んだ1本または2本のボーナスが追加されます。
